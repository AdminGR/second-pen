# User Jobs

Source: [Blueprint](../BRAINSTORMING/Second-Pen-BLUEPRINT.md) and [Path forward](../BRAINSTORMING/PATH_FORWARD.md).

## Primary Jobs

- Get a draft in my voice for a specific destination, from a spoken or typed brief, without re-explaining how I write.
- Review that draft the way it will be consumed: by reading it, or by hearing it read aloud.
- Push an accepted draft out of the tool into wherever it will actually be used.
- Keep sounding like the same author across Reels, web copy, manuals, and scripts.

## Secondary Jobs

- Correct a draft in place (edit) before pushing.
- Name a destination so pacing and sentence mechanics change, not just tone.
- Look back at a recent session without entering a content library.
- Seed or correct the underlying voice quietly, without making that the day's work.

## Friction Points

- Re-teaching a model every session.
- Drafts that live inside a scrolling chat and disappear.
- Reviewing spoken-for copy only with the eye.
- Tools that split "social," "docs," and "scripts" into different products or modes.
- Dashboards, template pickers, and settings that get in front of the job.

## Desired Outcomes

- One action is obvious on first glance.
- Twenty outputs stacked together still sound like one person.
- Push is a clear end of session, not an export buried in a menu.
- Mobile, one-handed dictation can start and finish the job. Desktop does the same job on a larger surface.
